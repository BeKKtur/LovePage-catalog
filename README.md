# INVITA

Next.js · TypeScript · Tailwind CSS · App Router.

## Запуск

```sh
npm install
npm run dev
```

## Проверки

```sh
npm run lint
npm run typecheck
npm run build
```

`npm run build` создаёт статический сайт в `out/`.

## Настройка

- `data/config.ts`: бренд, WhatsApp (международный номер, только цифры), Instagram и стартовые цены.
- `data/templates.ts`: все шаблоны. Добавьте объект, укажите цену, `coverImage` и при необходимости `demoUrl`. Ссылка на внешнее демо открывается напрямую; без неё доступно окно предпросмотра и локальное демонстрационное приглашение.
- `data/categories.ts`: коллекции. Добавьте запись для новой категории; тип категории и маршруты выводятся автоматически. Для SEO новой категории добавьте заголовок в `app/[category]/page.tsx`.
- `public/previews/`: оригинальные типографические SVG-обложки. Замените `coverImage` скриншотом вашего сайта в `public/`.

Имена, даты, подарок и ответы RSVP в демо — демонстрационные данные. RSVP не отправляется на сервер. До подключения WhatsApp заказ можно только скопировать: окно не имитирует отправку заявки. Музыка, карты и остальные персональные блоки добавляются в реальные клиентские проекты.
